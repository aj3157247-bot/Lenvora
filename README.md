# Lenvora V2

Multilingual offline dictionary and translator with OCR, Android app, admin panel, backend and advertisement management.

## Languages
- Persian (fa)
- English (en)
- Arabic (ar)
- Turkish (tr)
- German (de)
- French (fr)
- Spanish (es)

## Main features
- Offline dictionary
- Offline sentence translation
- Offline OCR from camera/images
- Multilingual UI with RTL/LTR support
- Admin dashboard
- Advertisement management
- Local caching and synchronization

This archive contains the project structure/scaffold. Implementation will be added module by module.
