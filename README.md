# Lenvora V2 Final App

A consolidated Android MVP source package:
- Offline Room dictionary
- Favorites and history
- ML Kit OCR
- On-device translation
- Language detection
- CameraX scanning
- Persian/English UI localization foundation
- Admin/advertisement API client foundation
- GitHub Actions Android build

Important:
- ML Kit translation models require a one-time download; after the model is installed, translation runs on-device.
- This ZIP is source code, not a signed APK.
- Before GitHub Actions can build, commit the Android Gradle Wrapper (`gradlew`, `gradlew.bat`, `gradle/wrapper/*`) to `android/`.
